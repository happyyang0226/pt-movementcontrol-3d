# 인체의 움직임 조절 — 1~6편 실사형 3D 강의 웹앱

청암대학교 물리치료과 강의용 웹앱입니다. 세포막 이온 펌프부터 대뇌 운동피질까지 6편, 편마다 9개 슬라이드로 구성됩니다.

## 들어 있는 기능
- **실사형 3D 시뮬레이션**(편마다 2종): Three.js r170 물리 기반 렌더링. 화면의 ✨ 고화질 / ⚡ 가볍게 버튼으로 화질을 바꿀 수 있습니다.
- **한국어 음성 나레이션**: 슬라이드별 해설을 읽어 줍니다.
- **자가 점검 퀴즈**: 편마다 5문항, 바로 채점하고 해설을 보여 줍니다.
- **✍ 내 필기**: 펜, 형광펜, 도형, 메모, 노트 파일 저장. 노트는 학생 브라우저에만 저장됩니다.
- **📖 용어 찾기**: 의학 용어 사전 147개, 강의 속 위치 찾기, 인터넷 찾기.
- **🖊 교수용 내용 수정**: 첫 화면에서 켜고, 수정한 내용을 넣은 새 파일을 저장합니다.

## 실행
`index.html` 하나로 동작합니다. 3D 라이브러리와 스타일은 CDN에서 불러오므로 인터넷 연결이 필요합니다.
